# Menu Digital — D’orus Assistência Técnica

Menu digital responsivo desenvolvido para centralizar os principais canais de atendimento da D’orus Assistência Técnica.

## Funcionalidades

- Solicitação de orçamento pelo WhatsApp com mensagem predefinida
- Acesso ao site oficial
- Ligação direta pelo celular
- Lista dos serviços atendidos
- Link para o Instagram da empresa
- Layout responsivo para celular e computador
- Identidade visual própria e acessibilidade básica

## Tecnologias

- HTML5 semântico
- CSS3 responsivo
- GitHub Pages

## Contexto do projeto

Projeto criado como parte de um trabalho de modernização da presença digital da D’orus Assistência Técnica, com foco em facilitar o contato, melhorar a apresentação da marca e aumentar a geração de chamados.
