# Site Institucional — D’orus Assistência Técnica

Site institucional responsivo desenvolvido para apresentar a história, os serviços e os canais de atendimento da D’orus Assistência Técnica em Guarulhos.

## Páginas

- Página Inicial
- Sobre
- Serviços
- Curiosidades e cuidados
- Fale conosco

## Funcionalidades

- Navegação completa entre páginas
- Formulário que prepara o chamado no WhatsApp
- Contato por celular e WhatsApp
- Link para localização no Google Maps
- Conteúdo educativo sobre eletrodomésticos
- SEO local e estrutura responsiva

## Tecnologias

- HTML5 semântico
- CSS3 responsivo
- JavaScript
- GitHub Pages

## Contexto do projeto

Projeto criado como parte da modernização da presença digital da D’orus Assistência Técnica, com foco em confiança, clareza e geração de chamados.
